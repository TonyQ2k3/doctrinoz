## Installation

The recommended way to install Doctrinoz is via `go install`

```powershell
go install github.com/TonyQ2k3/doctrinoz@latest
```

Alternatively, you can download [the latest release](https://github.com/TonyQ2k3/doctrinoz/releases/latest) for both Linux and Windows and run the tool's binary.
